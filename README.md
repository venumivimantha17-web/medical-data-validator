# Medical Data Validator

A Python-based project that validates patient medical records and identifies invalid or incorrectly formatted data.

## Features

- Validates medical record structure
- Checks patient and visit IDs
- Validates age and gender
- Checks diagnoses and medications
- Reports invalid records with their position and values

## Technologies

- Python
- Regular Expressions
- Lists and Dictionaries
- Functions and Loops

## Purpose

Created as part of the FreeCodeCamp Medical Data Validator workshop to practice Python data validation and error-handling techniques.
